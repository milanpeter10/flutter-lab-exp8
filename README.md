# Experiment 8 – Searching Information in Google Firestore Database

**Library Book Search System using Google Firestore** (Question 2 – Even Regnos, URK23CS7070)

## Aim

Develop a Flutter application that retrieves information from Google Firestore
based on user search input and displays the relevant information on the screen.

## Technology Stack

| Layer    | Technology                                  |
|----------|---------------------------------------------|
| Frontend | Flutter (Dart)                              |
| Backend  | Google Cloud Firestore (Firebase)           |
| IDE      | Visual Studio Code                          |
| Platform | Web (Chrome) – Android configured as well   |

## Features

- AppBar titled **Library Book Search**, a bordered `TextField` to enter the book title
  and a purple **Search** button.
- **Read only** – the app never adds or saves books; the `books` collection is
  filled manually in Firebase Console.
- On Search, the `books` collection is fetched with `books.get()` and the matching
  book is shown: **Title**, **Author**, **Copies Available**.
- Search is case-insensitive and ignores extra spaces
  (`"  artificial   INTELLIGENCE "` finds `Artificial Intelligence`).
- If `copies == 0`, a red warning **"Not Available – All Copies Issued"** is shown.
- If no book matches, **"Book not found"** is shown.
- Empty search shows **"Please enter a book title to search"**.
- `CircularProgressIndicator` while fetching; Firebase errors are caught and shown in red
  instead of crashing.
- Light background, responsive layout (max width 600 px, scrolls on small screens).

## Firestore Data Model

Collection: `books` (added manually in Firebase Console)

| Field    | Type   | Example        |
|----------|--------|----------------|
| `id`     | Auto ID / ISBN (document ID) | `qAZiAeDTp1wdnp1OrUig` |
| `title`  | string | Flutter Basics |
| `author` | string | John Smith     |
| `copies` | number | 5              |

Sample documents:

| title                   | author     | copies |
|-------------------------|------------|--------|
| Flutter Basics          | John Smith | 5      |
| Python Programming      | David      | 0      |
| Artificial Intelligence | Andrew     | 3      |

### Adding books in Firebase Console

1. Firebase Console → your project → **Firestore Database**.
2. **+ Start collection** → Collection ID `books` → **Next**.
3. Document ID: **Auto-ID**. Add fields `title` (string), `author` (string),
   `copies` (number) → **Save**.
4. Use **+ Add document** for the remaining books.

## Setup

The Firebase config files are not committed. Generate them for your own Firebase project:

```bash
dart pub global activate flutterfire_cli
flutterfire configure        # creates lib/firebase_options.dart and android/app/google-services.json
```

## Run

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d chrome        # or: flutter run (Android emulator / device)
```

End-to-end test (after `flutter build web`, needs Python + Playwright):

```bash
python tool/e2e_chrome_test.py screenshots
```
